    Getting in

    1. Unzip the folder anywhere you like: the desktop, documents, a USB stick. Keep everything inside it together.
    2. Double-click "Play Shattered Legacy". The first time only, it looks for Ultima Online on your computer. If it is not there it offers to fetch EA's free installer. Say yes, install it, and let the Ultima Online launcher finish updating before you close it. That part is about 2.5 GB and it only happens once.
    3. At the login screen, type any account name and password you want. Your first login creates your account, so write them down. After that, step 2 is all you ever need.

    Learning the world

    Where the shard stands

    Shattered Legacy is still being built. The progress page shows how much of the world is in place and how many known problems are still open, counted straight from the project's own records.

    If Windows complains

    It will, and nothing is wrong. The package is not code-signed, so Windows does not recognize it.

    A blue "Windows protected your PC" box: click More info, then Run anyway. An "Open File - Security Warning" box: click Run. If antivirus quarantines something, restore it or unzip the package again.

    If you would rather not click through a warning you do not understand, ask first.

    If something goes wrong

    "Cannot reach Shattered Legacy" means the server is not answering. It may be restarting. Wait a few minutes, then say something if it keeps happening.

    "Couldn't connect to Ultima Online. Please try again in a few moments", right after typing a new account name, is not what it sounds like. Waiting will not fix it. Say something and it can be sorted out in a minute.

    The wiki's troubleshooting page covers the common problems in more detail.

    Anything else: a photo or a screenshot of the window is worth more than a description.

    What is in the download

    The game client is TazUO, a free and open-source Ultima Online client, under the BSD 2-Clause license. The rest is a few small scripts that point it at this shard and start it.

    Nothing from EA is included. Ultima Online itself comes from EA's own free installer at uo.com, which the package fetches for you if you do not already have the game.
