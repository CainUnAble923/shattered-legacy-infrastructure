====== Getting connected ======

===== The short version =====

  - Go to [[https://shatteredlegacyuo.com|shatteredlegacyuo.com]] and click **Download and play**.
  - Unzip the folder anywhere and keep everything inside it together.
  - Double-click **Play Shattered Legacy**. The first time only, it looks for Ultima Online on your computer and offers to fetch EA's free installer if it is not there.
  - At the login screen, type any account name and password you want. Your first login creates your account, so write them down.
  - Continue to the [[:uo:new_player_guide|New player guide]].

===== Server =====

^ Item ^ Value ^
| Shard | ''Shattered Legacy'' |
| Address | ''shatteredlegacyuo.com'' |
| Port | ''2593'' |
| Client | TazUO, included in the player package |

The package is already pointed at the server. You only need these values if you set up a client yourself.
