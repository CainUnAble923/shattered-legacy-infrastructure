====== Troubleshooting ======

===== Windows warns about the download =====

It will, and nothing is wrong. The package is not code-signed, so Windows does not recognize it.

  * A blue **Windows protected your PC** box: click **More info**, then **Run anyway**.
  * An **Open File - Security Warning** box: click **Run**.
  * If antivirus quarantines something, restore it or unzip the package again.

===== The launcher says the client is missing =====

Windows' **Extract All** sometimes stops partway through without saying so. Delete the folder, unzip the package again, and check that everything came out.

===== "Cannot reach Shattered Legacy" =====

The server is not answering. It may be restarting. Wait a few minutes, then say something if it keeps happening.

===== "Couldn't connect to Ultima Online" right after a new account name =====

This one is not what it sounds like, and waiting will not fix it. Say something and it can be sorted out in a minute.

===== Anything else =====

A photo or a screenshot of the window is worth more than a description.
